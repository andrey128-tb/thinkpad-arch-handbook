# Chuẩn bị dữ liệu backup

Cần chuẩn bị 2 USB, 1 USB dùng để boot (USB boot) và 1 USB dùng để backup (USB backup).

Làm tuần tự các công việc sau:

- Chuẩn bị USB backup.
- Backup dữ liệu cá nhân trong `/home` .
- Backup danh sách package đã cài.
- Backup cấu hình Hyprland và Serpantinum.
- Backup cấu hình hệ thống cần thiết trong `/etc`.
- Kiểm tra backup có thể đọc được.
- Kiểm tra USB boot và USB backup.
- Kiểm tra ổ NVMe và tình trạng phần cứng.
- Ghi lại thông tin phân vùng hiện tại.
